# gprx

Flexible high-performance Gaussian process regression in Rust.

This crate is not published yet (`publish = false`). Phase 1 targets a local 0.1.0-quality API (README, rustdoc, examples) without crates.io.

## Status

Milestone **M0**: crate bootstrap and a faer Cholesky smoke test. Gaussian process types are not implemented yet.

Design: [`.dev/gprx-design.md`](.dev/gprx-design.md). Tasks: [`.dev/roadmap.md`](.dev/roadmap.md). Agent rules: [`AGENTS.md`](AGENTS.md).
